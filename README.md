# FLACMAN

FLACMAN is an Android music player project based on [PixelMusic](https://github.com/ianshulyadav/PixelMusic). This repository is a modified fork and is being developed under the FLACMAN name.

The project retains the **Material You / Material Design 3** visual direction. Its interface and features may evolve as FLACMAN development progresses.
